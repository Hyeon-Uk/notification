# iptables-restore

## NAME

iptables-restore - Restore IP Tables rules from stdin

## SYNOPSIS

```
iptables-restore [options]
```

## DESCRIPTION

`iptables-restore` is used to restore IP Tables rules from stdin. It reads rules in the format produced by `iptables-save` and restores them to the kernel. This is typically used in conjunction with `iptables-save` for backup and restore operations of firewall rules.

The utility reads the rule specification from standard input and restores the rules atomically, making it suitable for use in shell scripts and system initialization.

## OPTIONS

| Option | Description |
|--------|-------------|
| `-c`, `--counters` | Restore the values of all packet and byte counters |
| `-v`, `--verbose` | Print output to stdout while restoring rules |
| `-V`, `--version` | Print version information |
| `-h`, `--help` | Print help information |
| `-n`, `--noflush` | Don't flush the previous contents of the table. If not specified, all previous rules in the table are deleted before restoring the new rules |
| `-t`, `--test` | Only parse and construct the ruleset, but do not commit it |
| `-w`, `--wait` | Wait for the xtables lock |
| `-W`, `--wait-interval` | Wait interval for the xtables lock |

## EXAMPLES

### Restore rules from a file
```bash
iptables-restore < /etc/iptables/rules.v4
```

### Restore rules without flushing existing rules
```bash
iptables-restore -n < /etc/iptables/rules.v4
```

### Restore rules with verbose output
```bash
iptables-restore -v < /etc/iptables/rules.v4
```

### Restore rules with packet and byte counters
```bash
iptables-restore -c < /etc/iptables/rules.v4
```

### Backup and restore firewall rules
```bash
# Save current rules
iptables-save > /backup/iptables-backup.rules

# Restore rules
iptables-restore < /backup/iptables-backup.rules
```

### Restore rules with test mode
```bash
iptables-restore -t < /etc/iptables/rules.v4
```

## INPUT FORMAT

The input format used by `iptables-restore` consists of:

- Comments starting with `#`
- Table names prefixed with `*` (e.g., `*filter`, `*nat`)
- Built-in chain policies (e.g., `:INPUT ACCEPT [0:0]`)
- Rules in the same format as iptables command line

Example input:
```
# Generated by iptables-save
*filter
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
-A INPUT -p tcp --dport 22 -j ACCEPT
COMMIT
```

## FILES

| File | Description |
|------|-------------|
| `/etc/iptables/rules.v4` | Default IPv4 rules file |
| `/etc/sysconfig/iptables` | Red Hat based systems rules file |
| `/var/lib/iptables/rules` | Alternative rules storage location |

## EXIT STATUS

| Status | Description |
|--------|-------------|
| 0 | Success |
| 1 | Failure (invalid input, parse error, etc.) |
