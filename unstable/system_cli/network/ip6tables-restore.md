# ip6tables-restore

## NAME

ip6tables-restore - Restore IPv6 Tables rules from stdin

## SYNOPSIS

```
ip6tables-restore [options]
```

## DESCRIPTION

`ip6tables-restore` is used to restore IPv6 Tables rules from stdin. It reads rules in the format produced by `ip6tables-save` and restores them to the kernel. This is typically used in conjunction with `ip6tables-save` for backup and restore operations of IPv6 firewall rules.

The utility reads the rule specification from standard input and restores the rules atomically, making it suitable for use in shell scripts and system initialization.

## OPTIONS

| Option | Description |
|--------|-------------|
| `-c`, `--counters` | Restore the values of all packet and byte counters |
| `-v`, `--verbose` | Print output to stdout while restoring rules |
| `-V`, `--version` | Print version information |
| `-h`, `--help` | Print help information |
| `-n`, `--noflush` | Don't flush the previous contents of the table. If not specified, all previous rules in the table are deleted before restoring the new rules |
| `-t`, `--test` | Only parse and construct the ruleset, but do not commit it |
| `-w`, `--wait` | Wait for the xtables lock |
| `-W`, `--wait-interval` | Wait interval for the xtables lock |

## EXAMPLES

### Restore IPv6 rules from a file
```bash
ip6tables-restore < /etc/iptables/rules.v6
```

### Restore rules without flushing existing rules
```bash
ip6tables-restore -n < /etc/iptables/rules.v6
```

### Restore rules with verbose output
```bash
ip6tables-restore -v < /etc/iptables/rules.v6
```

### Restore rules with packet and byte counters
```bash
ip6tables-restore -c < /etc/iptables/rules.v6
```

### Backup and restore IPv6 firewall rules
```bash
# Save current rules
ip6tables-save > /backup/ip6tables-backup.rules

# Restore rules
ip6tables-restore < /backup/ip6tables-backup.rules
```

### Restore rules with test mode
```bash
ip6tables-restore -t < /etc/iptables/rules.v6
```

## INPUT FORMAT

The input format used by `ip6tables-restore` consists of:

- Comments starting with `#`
- Table names prefixed with `*` (e.g., `*filter`, `*nat`)
- Built-in chain policies (e.g., `:INPUT ACCEPT [0:0]`)
- Rules in the same format as ip6tables command line

Example input:
```
# Generated by ip6tables-save
*filter
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
-A INPUT -p tcp --dport 22 -j ACCEPT
-A INPUT -s 2001:db8::/32 -j ACCEPT
COMMIT
```

## FILES

| File | Description |
|------|-------------|
| `/etc/iptables/rules.v6` | Default IPv6 rules file |
| `/etc/sysconfig/ip6tables` | Red Hat based systems rules file |
| `/var/lib/iptables/rules.v6` | Alternative rules storage location |

## EXIT STATUS

| Status | Description |
|--------|-------------|
| 0 | Success |
| 1 | Failure (invalid input, parse error, etc.) |
