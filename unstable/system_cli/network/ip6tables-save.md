# ip6tables-save

## NAME

ip6tables-save - Dump IPv6 tables rules to stdout

## SYNOPSIS

```
ip6tables-save [options]
```

## DESCRIPTION

`ip6tables-save` is used to dump the contents of IPv6 Tables in a format that can be parsed by `ip6tables-restore`. This utility is useful for creating backup files of your IPv6 firewall configuration or for viewing the current ruleset in a machine-readable format.

The output format is designed to be easily parsed and can be redirected to a file for backup purposes.

## OPTIONS

| Option | Description |
|--------|-------------|
| `-c`, `--counters` | Include the current values of all packet and byte counters in the output |
| `-t`, `--table table` | Restrict output to only the specified table. If not specified, all tables are dumped |
| `-V`, `--version` | Print version information |
| `-h`, `--help` | Print help information |
| `-M`, `--modprobe modprobe_program` | Specify the path to the modprobe program |

## EXAMPLES

### Save all IPv6 rules to a file
```bash
ip6tables-save > /etc/iptables/rules.v6
```

### Save rules with packet and byte counters
```bash
ip6tables-save -c > /backup/ip6tables-with-counters.rules
```

### Save only the filter table
```bash
ip6tables-save -t filter > /backup/filter-rules.v6
```

### Save only the NAT table
```bash
ip6tables-save -t nat > /backup/nat-rules.v6
```

### View current rules on screen
```bash
ip6tables-save
```

### Backup and restore workflow
```bash
# Backup current rules
ip6tables-save > /backup/ip6tables-backup.rules

# Modify rules...
ip6tables -A INPUT -p tcp --dport 80 -j ACCEPT

# Restore from backup if needed
ip6tables-restore < /backup/ip6tables-backup.rules
```

## OUTPUT FORMAT

The output consists of:

- Comments starting with `#` (e.g., `# Generated by ip6tables-save`)
- Table names prefixed with `*` (e.g., `*filter`, `*nat`, `*mangle`)
- Built-in chain policies (e.g., `:INPUT ACCEPT [0:0]`)
- Rules prefixed with `-A` (append)
- Table sections end with `COMMIT`

Example output:
```
# Generated by ip6tables-save
*filter
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [0:0]
-A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
-A INPUT -p tcp --dport 22 -j ACCEPT
-A INPUT -s 2001:db8::/32 -j ACCEPT
COMMIT
```

## FILES

| File | Description |
|------|-------------|
| `/etc/iptables/rules.v6` | Default IPv6 rules file |
| `/etc/sysconfig/ip6tables` | Red Hat based systems rules file |

## EXIT STATUS

| Status | Description |
|--------|-------------|
| 0 | Success |
| 1 | Failure |
