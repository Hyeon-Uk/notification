# COMPMGR_TOOL

**NAME**

compmgr_tool - component manager tool for AUL

**SYNOPSIS**

```
compmgr_tool [OPTIONS]
```

**DESCRIPTION**

`compmgr_tool` is a command-line utility for managing application components in Tizen's AUL (Application Utility Library) framework. It provides operations for managing component lifecycle and inter-component communication.

**OPTIONS**

| Option | Description |
|--------|-------------|
| `-h, --help` | Display help message |

**PACKAGE**

platform/core/appfw/aul-1
